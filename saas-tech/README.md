# saas-tech

This bundle deploys a **Genie Space** for the SaaS Tech industry use case, backed by synthetic data generated by the included `data_generation` job.

## Prerequisites

Run the data_generation notebook in /notebooks, replacing the widgets with your own catalog and schema. 

Next, before deploying the bundle, update the `databricks.yml` file with your own values:

### 1. Workspace URL

Replace the placeholder in `targets.dev.workspace.host` with your Databricks workspace URL:

```yaml
targets:
  dev:
    workspace:
      host: https://YOUR_WORKSPACE_URL.cloud.databricks.com  # Replace with your workspace URL
```

You can find your workspace URL in the address bar of your browser when logged into Databricks (e.g. `https://adb-1234567890.1.azuredatabricks.net`).

### 2. SQL Warehouse ID

Replace the placeholder in `variables.warehouse_id.default` with the ID of an existing SQL Warehouse:

```yaml
variables:
  warehouse_id:
    default: "REPLACE_WITH_WAREHOUSE_ID"  # Replace with your SQL Warehouse ID
```

To find your SQL Warehouse ID:
1. Go to **SQL Warehouses** in the left sidebar
2. Click on your warehouse
3. Copy the **ID** shown at the top of the page (or from the URL)

### 3. Catalog and Schema

Replace CATALOG and SCHEMA inside of the serialized genie space json file (CMD+F on CATALOG, click the arrow on the left, type your value in the "replace" input, and click "Replace All". Do the same for SCHEMA).

---

## Getting Started

### Step 1 — Deploy the bundle

Click the **deployment rocket** in the left sidebar to open the **Deployments** panel, then click **Deploy**.

### Step 2 — Run the Data Generation job

Before the Genie Space can answer questions, the underlying tables must be populated. Run the **[saas-tech] Data Generation** job to generate all required synthetic Delta tables in your catalog and schema.

Once the job completes successfully, the Genie Space is ready to use.
